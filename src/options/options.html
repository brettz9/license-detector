License Detector

Blocking

Detection always runs. Blocking is optional and off by default: when enabled, scripts whose license category isn't in your allowed list below are blocked.

Some licenses aren't declared with an explicit, unambiguous tag and are instead inferred from a license name or URL found in the page — shown as "best guess" in the popup. A guess can be wrong (e.g. by matching an unrelated word), so enabling this treats guessed licenses as not allowed, even if the guessed category itself would otherwise be allowed below.

Allowed license categories

Scripts in a category not checked here are flagged, and (if blocking is enabled) blocked.
